# GPT Image App

Flutter AI Image Generation App - Doubao Style

## 功能特点

- 🎨 **文生图**: 输入描述词，让AI生成图片
- ✏️ **图片编辑**: 上传图片 + 编辑指令，AI帮你修改
- 🔄 **多图融合**: 上传多张图片，AI融合创作
- 💬 **多轮对话**: 支持持续对话修改图片
- 📱 **历史记录**: 保存所有对话历史

## 使用说明

1. 在设置中配置 API Key
2. 输入图片描述或上传参考图
3. 点击发送，AI 生成图片
4. 可点击图片查看大图并保存

## 技术栈

- Flutter
- Material Design 3
- 豆包App风格UI
